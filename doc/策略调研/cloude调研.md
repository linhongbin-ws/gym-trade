# 美股分钟级 Intraday Trading 策略总结

> 基于工业界实践的系统性梳理，涵盖信号体系、选股器、分钟级交易策略与风控框架。

---

## 一、工业界 Intraday Trading 方法概览

### 核心信号来源（Alpha 信号）

**1. 日内动量（Intraday Momentum）**
- 开盘前30分钟收益可预测收盘前30分钟收益（Gao et al. 经典结论）
- VWAP偏离度：判断趋势延续 vs 均值回复
- 成交量加权动量：价格 + 量共同确认趋势

**2. 开盘区间突破（ORB, Opening Range Breakout）**
- 5分钟 ORB 是研究最充分的版本
- 仅在"当日活跃股（Stocks in Play）"有效，普通股票胜率大幅下降
- 突破需成交量配合，否则假突破概率高

**3. 日内均值回复（Intraday Mean Reversion）**
- 短期偏离均衡后回复，在低波动、高流动性时段最有效
- VWAP 均值回复：大幅偏离后做反向，以 VWAP 为止盈目标
- 日内配对交易：相关股票之间的价差回复

**4. 日内横截面因子**
- 过去 N 分钟收益率排名（横截面动量）
- 成交量异动：当前量 vs 历史同时段均量
- 相对强弱：个股 vs 行业/大盘的相对表现

**5. 日内时段效应**
- 开盘效应（9:30–10:00）：波动最大，动量信号强
- 午盘低谷（12:00–13:30）：流动性差，回避
- 收盘前效应（15:30–16:00）：机构调仓集中，动量重新变强

### 模型与建模范式

| 模型类型 | 特点 | 适用场景 |
|---------|------|---------|
| GBDT（LightGBM/XGBoost） | 首选，速度快、抗过拟合 | 分钟级特征预测 |
| CNN + GRU / Transformer | 时序建模能力强 | 价格序列深度挖掘 |
| 强化学习（RL） | 动态仓位调整 | 复杂市场状态 |
| 集成模型（Ensemble） | 综合多种信号 | 提升稳定性 |

### 通用特征工程框架

```
价格类：open/high/low/close、各时间窗口 return、gap
成交量类：volume ratio（当前 vs 历史同时段）、成交量加速度
技术指标：VWAP、ATR、RSI、布林带宽度
跨周期特征：1min/5min/15min/30min 多尺度动量组合
日历特征：时段（9:30–10:00 等）、星期、距离重要事件天数
市场状态特征：VIX 水平、大盘当日涨跌幅、行业 ETF 相对强弱
```

## 二、四套完整策略

---

### 套一：催化剂驱动的 Gap & Go 动量策略

**适合：** 做单股、追热点、小规模资金

#### 选股器（盘前完成）

```
筛选条件（按优先级）：
1. Gap幅度 > 4%（相对昨日收盘）
2. 必须有明确催化剂：
   - 财报超预期（EPS beat > 10%）
   - FDA 批准 / 重大新闻 PR
   - 分析师评级上调 / 并购传闻
3. 盘前成交量 > 历史盘前均量的 3倍
4. 价格区间 $2–$100（流动性适中）
5. 优先选 float 小（流通股 < 2000万）的标的
```

#### 分钟级交易逻辑

```
时间窗口：9:30–10:00

入场：
  - 等待开盘第1根1min K线收盘
  - 收盘价 > 盘前高点 → 做多，止损设在该K线低点
  - 价格突破后回踩VWAP不破 → 追入第二波

确认条件：
  - 价格站在 VWAP 之上
  - 成交量持续放大（每根K线 > 前一根）
  - 排除开盘即见顶的"假突破"形态
```

#### 退出规则

```
止盈：分批减仓（50%在+3%, 剩余用追踪止损）
止损：跌破1min开盘K线低点 或 跌破VWAP
时间止损：10:00后若无新高 → 全清仓
```

**核心优势：** 有催化剂驱动，胜率高  
**核心风险：** 假突破、追高；开盘噪音大

### 套二：日内横截面动量策略（机构主流）

**适合：** 做股票池、量化系统、中等规模资金

#### 选股器（静态池 + 每日动态打分）

**静态股票池建立（每周更新）：**
```
基础池：Russell 1000 或 S&P 500 成分股
流动性过滤：
  - 30日均量 > 200万股/天
  - 价格 > $5，市值 > $5亿
排除：即将财报（±2天）、停牌
```

**每日动态打分（开盘前）：**

| 因子 | 计算方式 | 权重 |
|------|---------|------|
| 隔夜动量 | 昨日收盘→今日开盘涨跌幅 | 25% |
| 5日相对强弱 | 个股5日收益 - 行业ETF5日收益 | 25% |
| 量比 | 盘前成交量 / 历史同期均值 | 20% |
| 特质波动率 | 近20日日内收益率标准差 | -15%（惩罚） |
| 隔夜Gap | 今日gap幅度 | 15% |

→ 综合打分，选 **Top 20 做多 / Bottom 20 做空**

#### 分钟级交易逻辑

```
时间窗口：10:00–15:30（避开开收盘噪音）

信号生成（每5分钟滚动）：
  - 计算每只股票过去30分钟收益排名
  - 持续排名前10%且VWAP上方 → 做多信号
  - 持续排名后10%且VWAP下方 → 做空信号

入场条件（双重确认）：
  1. 横截面排名信号触发
  2. 价格相对VWAP偏离 < 1.5%（避免追高）

仓位管理：
  - 单股不超过总仓位5%
  - 多空对冲，beta中性（多头beta ≈ 空头beta）
  - 按个股ATR调整仓位大小
```

#### 退出规则

```
持仓时长：30分钟–2小时
退出信号：
  - 横截面排名跌出前20%
  - 价格跌破VWAP（多头）/ 涨过VWAP（空头）
  - 最大持仓时间到期强制平仓
硬止损：单股亏损 > ATR × 2
```

**核心优势：** 多空对冲，低市场系统性风险  
**核心风险：** 选股模型过拟合；换手率高，成本压力大

### 套三：开盘反转 + VWAP 均值回复策略

**适合：** 震荡市环境、流动性好的大盘股/ETF

**核心逻辑：** 研究发现美股开盘前30分钟涨幅强的股票，当天剩余时间往往表现偏弱，开盘收益与后续盘中收益呈显著负相关。

#### 选股器（10:00时运行）

```
筛选条件：
1. 前30分钟涨幅 > +3% 或 < -3%
2. 无明确催化剂（区别于套一！）
   - 无财报、无重大事件，纯情绪推动
3. 价格距VWAP偏离 > 1.5%
4. RSI(14) on 5min > 75 或 < 25
5. 优先大盘股（SPY成分），流动性好

信号：开盘涨过头 → 做空；开盘跌过头 → 做多
```

#### 分钟级交易逻辑

```
时间窗口：10:00–14:00（均值回复效应最强）

入场：
  - 价格开始向VWAP方向回归
  - 5min K线出现反转形态
  - VWAP偏离 > 1.5%（统计显著超买/超卖）
  - 成交量开始萎缩（追涨动能消退信号）

目标价位：
  - 第一目标：VWAP（60%仓位止盈）
  - 第二目标：VWAP ± 0.5%（剩余40%）
```

#### 退出规则

```
止损：价格继续突破今日高/低点
止盈：价格回到VWAP附近
时间止损：14:30后若未到目标价 → 强制平仓
禁忌：趋势强烈时逆势加仓（趋势日会大亏）
```

**核心优势：** 逻辑简单清晰，震荡市稳定  
**核心风险：** 趋势日逆势交易，需 regime 识别

### 套四：ML 多因子日内预测策略（系统化最高形态）

**适合：** 有工程能力的量化团队、中大规模资金

#### 选股器（静态 + 实时双层）

**第一层（静态，每周更新）：**
```
Russell 3000 中筛选：
  - 日均成交额 > $5000万
  - 近60日无极端跳空（>20%单日）
  - 历史数据完整
→ 约500–800只股票进入动态池
```

**第二层（实时，每分钟更新 ML 打分）：**

```
特征工程（每分钟重新计算）：

价格类：
  - 1/5/15/30min return
  - 价格相对VWAP偏离百分比
  - 开盘gap幅度

成交量类：
  - 当前成交量 / 历史同时段均量（量比）
  - 成交量加速度（量比变化率）

技术指标：
  - RSI(5), RSI(14) on 1min/5min
  - 布林带位置（上/中/下轨距离）
  - ATR（波动率标准化用）

市场状态类：
  - SPY当日涨跌幅
  - VIX水平
  - 行业ETF相对强弱
  - 时段特征（开盘/午盘/尾盘）

目标变量：未来30分钟收益率方向（+1/-1/0）
模型：LightGBM，滚动训练（每季度更新）
```

#### 分钟级交易逻辑

```
触发条件（三重确认）：
  - ML预测概率 > 65%
  - 与当前VWAP位置方向一致
  - 成交量信号确认（量比 > 1.5）

仓位管理：
  - Kelly公式缩水版（取Kelly值25%，保守）
  - 按ATR反比例分配（波动大的给小仓位）
  - 全组合 beta 中性对冲

执行：
  - 用TWAP/VWAP算法分批成交（减少冲击成本）
  - 单次成交不超过该股5分钟均量的10%
```

#### 退出规则

```
退出信号：
  - ML信号反转（概率跌破45%）
  - 持仓超过60分钟
  - 价格突破止损线（ATR × 1.5）

日内风控：
  - 单策略日亏损 > 0.3% AUM → 停止当日交易
  - 最大持仓股票数量上限：50只
  - 15:45 全部清仓，不过夜
```

**核心优势：** 综合alpha最强，自动化程度高  
**核心风险：** 模型过拟合、特征失效；工程复杂度高

## 四、通用风控原则

> 分钟级交易中，**风控比信号更重要**。

1. **避开财报日前后2天** — 跳空无法有效止损
2. **避开 Fed 讲话 / 重大宏观数据发布时段** — 事件驱动跳空会破坏所有日内模型
3. **单日亏损超 1% AUM → 当日停止交易** — 保护资金，避免情绪化操作
4. **15:45 前全清仓** — 不承担隔夜风险
5. **回测必须含真实买卖价差和滑点** — 分钟级换手率极高，忽视成本的回测结果无效
6. **容量约束意识** — 很多分钟级策略在小资金有效，规模上去后 alpha 快速衰减
7. **仓位按波动率（ATR）缩放** — 高波动标的自动减仓

## 五、关键指标参考

| 指标 | 说明 | 参考阈值 |
|------|------|---------|
| VWAP 偏离 | 价格相对VWAP的百分比距离 | >1.5% 触发均值回复信号 |
| 量比（Relative Volume） | 当前量 / 历史同时段均量 | >3x 为异常高量 |
| ATR | 平均真实波动幅度 | 止损设置基准（1.5–2x ATR） |
| RSI（5min） | 短周期超买超卖 | >75 超买 / <25 超卖 |
| ML预测概率 | 模型置信度 | >65% 入场 / <45% 退出 |
| Gap幅度 | 相对昨日收盘的跳空幅度 | >4% 触发 Gap & Go 扫描 |
